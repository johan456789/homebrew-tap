# homebrew-tap

Personal Homebrew tap for custom formulae.

## Install

```bash
brew tap johan456789/tap
```

## Included formulae

- `ffmpeg-zscale`: FFmpeg built from source with `--enable-libzimg` and `--enable-libx265`, installed as `ffmpeg-zscale` and `ffprobe-zscale`.
- `ghspeed`: Check GitHub/Fastly download health from your current network (Fastly POP, packet loss, throughput, OK/SLOW/DEGRADED verdict).
